# 技術指標研究所本地版

這是繁體中文股票技術指標教學網站的本地版本。第一版使用本地保存的真實歷史日線快照，不接即時行情，不提供交易功能，也不構成投資建議。

## 打開網站

1. 在這個資料夾啟動本地伺服器。
2. 用瀏覽器打開 `http://127.0.0.1:4173/`。
3. 若只想快速查看，也可以直接打開 `index.html`，但建議使用本地伺服器，頁面路由會較穩定。

## 已有功能

- 82 個技術指標百科頁，全部按入門/中級/進階分級展示。
- 10/10 學習路線與市況導航：先判斷趨勢、震盪、突破或恐慌，再選工具。
- 首頁指標選擇小助手，可按用途和難度推薦學習入口。
- 指標搜尋、分類、用途和難度篩選。
- 術語即時速查，可在術語表和指標頁快速查 R 值、背離、鈍化等概念，並附交易例子。
- 指標詳情頁：案例、公式、大師實戰地圖、交易劇本、風險回報、錯誤、反面教材、FAQ。
- 指標圖表示範已接入本地真實 OHLCV 快照：按指標類型配對 AAPL、SPY、QQQ、0700.HK 等市況案例，以收市價折線為主、淡色陰陽燭作輔助，並標示股票名稱、時間、入場價、止損價、2R 目標和後續檢查價。
- 陰陽燭教學專區：結構、30 個入門/中級/進階形態、情境判讀、交易劇本、錯誤案例和判讀小工具。
- 交易計算器：做多/做空方向、費用/滑價、扣費後 R 值、打和勝率、最大股數。
- 交易前檢查卡和本地交易備註。
- 互動練習場、即時小測驗和實戰練習任務。
- 歷史型市況案例庫：恐慌急跌、下降趨勢、主升段、港股消息裂口，並配合案例測驗。
- 測驗成績記錄、交易日誌統計圖、交易日誌教練洞察、10 分制指標組合檢查器。
- 指標比較頁加入互動比較選擇器，用來檢查互補與重複計票。
- TradingView 策略研究專題，包含 Strategy Tester 閱讀、策略研究工作台、回測可信度評分和過度擬合紅旗。
- 收藏、訂閱示範、本地資料匯出與合併匯入，並按學習狀態提示下一步。

## 本地資料

收藏、email 示範和指標備註只保存在目前瀏覽器。若清除瀏覽器資料，這些內容可能消失。可在「收藏/訂閱與本地資料」頁匯出 JSON 備份。

## 內容定位

本網站用於教育和交易前思考訓練。技術指標只能描述歷史價格與成交量，不能保證未來走勢。任何交易都應先定義入場、止損、目標、倉位和最大可承受虧損。

## 品質審核

本地 10/10 升級審核記錄在 `QUALITY_AUDIT.md`，包含需求對照、主要升級、已執行驗證和後續可選升級。

## 分頁圖片

所有分頁圖片提示詞已整理在 `IMAGE_PROMPTS.md`。生成後的高清圖片已放在 `assets/generated-pages/`，並接入首頁、全部指標、指標詳情、比較、練習場、TradingView 策略研究、交易日誌、術語表、指標組合檢查器和收藏/訂閱頁。
